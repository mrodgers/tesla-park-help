Neighbor helper guide

Tesla Park helper FAQ

Thank you for helping a neighbor keep a guest parking code visible on a car display. This is email-only and takes about a minute when you have a code to share.

What this is

Sometimes the primary monthly guest-pass allotment runs low. If you can spare a guest code from your own parking portal, you can email it so it can be shown on the car’s small display for plate EV14E28.

What we never ask for

  • Your password
  • Your parking-portal login
  • Any app install or account access

Codes by email are enough.

Where to send codes

Email:

mrodgers.junk@gmail.com

What to include

  • The guest code / permit number
  • Plate EV14E28 if the pass is tied to a vehicle
  • Valid-through date/time if you know it

A short subject like “guest code” is fine. Plain text is perfect.

How to stop

If you are out of codes for the month (or need a break), just email that you’re out. No forms, no account to cancel.

Privacy

Codes are used only to update the display for that car. They are not shared with others or used for anything else.

Questions? Reply to the intro email you received, or write mrodgers.junk@gmail.com.
