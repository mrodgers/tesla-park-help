# Tesla Park — helper FAQ

Public one-pager for people who email guest parking codes to help a neighbor’s car display.

- **Live page:** https://mrodgers.github.io/tesla-park-help/
- **Source:** `index.html` (GitHub Pages from `main` / root)

## What this site is for
Warm, plain-language instructions: email codes to the junk inbox, what to include, how to stop, privacy. No passwords, no portal login, no apps.

## What must never appear here
Private IPs, MAC addresses, mesh/channel keys, portal usernames, firmware details, allotment-automation internals, or helper email addresses beyond the shared intake address already listed on the page.

## Local preview
Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

## Operator docs
Private protocol lives in the `tesla-park` firmware/docs repo (`docs/helpers.md`) and the operator agent’s `notes/helpers/` registry — not in this public repo.
